Lanjutkan implementasi Pagination, Filter, Sorting, dan Summary Dashboard untuk halaman Draf Perjanjian Tenant.

Sebelum coding:

1. Baca seluruh implementasi:

   * routes/draft-agreements.ts
   * halaman admin draf-perjanjian.tsx
   * query hooks terkait
   * tabel tenant_draft_agreements
2. Audit endpoint GET saat ini agar tidak merusak kompatibilitas frontend yang sudah berjalan.

=====================================
FASE 1 — Backend Pagination & Filter
====================================

Upgrade endpoint:

GET /api/draft-agreements

Tambahkan query parameter:

?page=1
?limit=20
?status=pending
?siteId=1
?source=self_register
?search=nama
?dateFrom=2026-01-01
?dateTo=2026-12-31
?sortBy=created_at
?sortDir=desc

Filter yang wajib didukung:

* status
* site_id
* source
* tanggal
* keyword search

Keyword search harus mencari ke:

* nama calon tenant
* nama brand
* email
* whatsapp

Response baru:

{
"success": true,
"data": [...],
"pagination": {
"page": 1,
"limit": 20,
"total": 125,
"totalPages": 7,
"hasNext": true,
"hasPrev": false
}
}

Gunakan SQL yang efisien.
Hindari query N+1.

FASE 2 — Summary Cards
